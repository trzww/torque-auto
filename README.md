# Torque Auto Service Website

Premium responsive website for Torque Auto Service, Doha, Qatar.

## Project files
- `index.html` — page structure and content
- `styles.css` — responsive visual system and animations
- `script.js` — mobile navigation, scroll reveals and video behavior
- `favicon.svg` — custom Torque mark

## Media
The page references the original photos and video uploaded to the repository root. Keep their filenames unchanged unless you also update the references in `index.html` and `styles.css`.

## Deploy
Static site; no build command required. Use the repository root as the output directory for GitHub Pages or Cloudflare Pages.

## Pre-delivery checks
Verify service details, contact information, social links, map pin, logo/brand approval, image selection, video playback, responsive layouts and the live deployment URL with the client.
